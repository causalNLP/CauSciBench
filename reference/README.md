# Reference

This folder contains the reference files for the studies included in CauSciBench. Each file serves as a pointer to the original papers and queries used in the benchmark, including metadata such as the paper name, query, causal method, answer, and link to the source data.

- `reference_real.xlsx` — references for the real-world paper replications. For each study, the reference points to the specific table, figure, or section in the original paper where the result of interest is presented. 
- `reference_qr.xlsx` — references for the QRData queries. For each entry, the reference is the exact query used in the benchmark. The dataset names are unchanged.
