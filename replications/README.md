# Replications

This folder contains the code to reproduce the causal analyses included in CauSciBench. The replications have been generated with the help of source code provided by the original authors. In cases where no code was available, the authors performed the replications themselves.

## Organization

- **Real-world papers**: Solutions are organized by paper, each in its own module under `real/`.
- **QRData**: Solutions are organized by individual query in `qrdata.py`.

## Notebooks

- `qrdata_notebook.ipynb` — shows the results of running the QRData replications.
- `realdata_notebook.ipynb` — shows the results of running the real-world paper replications.
